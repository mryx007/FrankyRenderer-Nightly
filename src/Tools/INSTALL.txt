FrankyRenderer - Windows x64

One native package for PotPlayer and MPC-BE.
Requires PotPlayer 261030 Beta 64-bit or newer with native FrankyRenderer support,
or MPC-BE with FrankyRenderer support.

Extract to a permanent folder, close all video players, right-click Install.cmd
and choose Run as administrator.
Select FrankyRenderer in the player's video renderer settings.
Run Uninstall.cmd the same way before moving or removing the installed folder.
Player packages: Install.cmd /s and Uninstall.cmd /s run without messages;
exit code 0 means success.
The original MPC Video Renderer may remain installed.
Dolby Vision Profile 7 FEL/MEL processing is automatic; no additional filter is required.

Tested on Windows 11 x64. Windows 10 x64 is expected to work but is untested.

PotPlayer beta download: https://t1.daumcdn.net/potplayer/beta/PotPlayerSetup64.exe
